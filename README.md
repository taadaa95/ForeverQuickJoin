# Forever QuickJoin
**Find Groups Faster. One-Click Whisper.**

Forever QuickJoin is an enhanced group finder addon built specifically for **WoW Forever**. Browse group listings, discover recruitment messages from LFG Chat, and contact group leaders with a single click.

### Key Features

- **One-Click Whisper** — Instantly send a customizable recruitment whisper to group leaders without typing manually.
- **Integrated LFG Chat** — Discover recruitment messages from LookingForGroup, General, Trade, and other public channels.
- **Smart Group Filtering** — Find relevant groups using activity, role, class, and playstyle filters.
- **Party Role Manager** — Track your party composition and manually correct Tank, Healer, and DPS assignments.
- **Quick Invite** — Invite eligible players directly from group listings or LFG Chat.
- **Group Management** — Create listings, manage applicants, and keep recruitment conversations organized.
- **Blizzard-Inspired Interface** — Familiar visuals, multiple themes, and customizable whisper templates.

**Less searching. Less typing. More playing.**
